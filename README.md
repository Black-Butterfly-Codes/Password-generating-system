# Password Generator

A simple and efficient password generator written in C that creates random passwords based on a user-defined length. This project is designed to help users generate stronger passwords while providing hands-on practice with C programming concepts.

## Features

* Generate passwords of custom length
* Random password generation
* Supports:

  * Uppercase letters (A-Z)
  * Lowercase letters (a-z)
  * Numbers (0-9)
  * Special characters
* Easy-to-use command-line interface

## Technologies Used

* C Programming Language
* GCC Compiler
* Git
* GitHub

## Learning Objectives

This project was built to practice:

* Variables and data types
* Arrays and strings
* Loops and conditional statements
* Functions
* Random number generation
* Version control with Git and GitHub

## Future Improvements
